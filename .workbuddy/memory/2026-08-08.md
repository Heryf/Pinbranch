## 2026-08-09 性能深度分析

### 参考网站对比分析
- 参考网站 ai.zhanglearning.com 也是 Pintree 项目，技术栈相同
- 参考网站快的原因：数据量小（书签分散在子文件夹），每次加载 < 30 条
- 你的网站慢的原因：搜罗美食合集 648 条书签在根目录，一次全量加载

### 9 大性能问题已定位
1. **三重重复 API 调用**：/api/collections 被 page.tsx + sidebar.tsx + CollectionGrid.tsx 各调一次
2. **648 条书签无分页**：API 返回全部书签，前端渲染 648 个 BookmarkCard + 648 张图片
3. **N+1 查询**：每个子文件夹 2 次 count 查询
4. **layout.tsx generateMetadata 阻塞**：每次请求 5 次 DB 查询才返回 HTML
5. **API 瀑布流**：9-13 次串行 API/DB 调用
6. **图片未优化**：unoptimized: true，648 张全尺寸图片
7. **未使用重型依赖**：dnd-kit(4包)、embla-carousel、react-dropzone、uploadthing、remixicon
8. **BookmarkCard 用 next/image 但 unoptimized**：最重的组件无优化效果
9. **settings API force-dynamic**：无缓存
