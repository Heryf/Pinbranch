## 2026-08-05 修改记录

### 1. 私密文件夹功能修复
- **EditFolderDialog.tsx**: 将"公开访问"改为"私密访问"，逻辑清晰：关闭=公开，打开=私密+密码
- **API `/api/folders/[id]`**: 支持 password 更新，空密码时自动清理
- **API `/api/collections/[id]/bookmarks`**: 添加密码验证，非公开文件夹返回 403 需密码
- **API `/api/collections/[id]/folders`**: 安全处理，不返回 password 字段，添加 `isPrivate` 标志
- **PasswordDialog.tsx**: 新建密码验证弹窗组件，支持输入/显示切换/错误提示
- **BookmarkGrid.tsx**: 集成密码验证逻辑，sessionStorage 缓存已验证密码，支持访问被拒绝状态和重新输入
- **FolderCard.tsx**: 私密文件夹显示锁图标（`Lock` from lucide-react）和"已上锁"标记

### 2. UI标题修复
- **header.tsx**: 移除中间多余的"Pinbranch"标题（sidebar 已显示网站名称）
- **sidebar.tsx**: 修复左上角标题垂直居中，`justify-center` 替代 `justify-start`

### 3. 搜索栏全局化
- **page.tsx**: 将 SearchBar 从 BookmarkGrid 提取到全局渲染，位于 Header 下方，切换文件夹不再重复渲染
- **BookmarkGrid.tsx**: 移除 SearchBar 和 enableSearch 加载逻辑，搜索状态通过 props 传入
- 搜索状态（query/scope/engine）在 page 层管理，BookmarkGrid 只负责显示搜索结果

### 4. 性能优化
- **loading.tsx**: 创建全局首屏加载骨架，减少白屏等待感知
- **PERFORMANCE_ANALYSIS.md**: 完整性能分析报告，包含7项优化建议及优先级排序
- TypeScript 编译检查通过，无错误
