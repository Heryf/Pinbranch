# 2026-08-31 工作日志

## 修复三个 Bug

### Bug 1 - 搜索后导航跳转异常
- **根因**: `page.tsx` 中 `searchQuery` 在切换合集/文件夹/返回首页时未被清空，`BookmarkGrid` 继续显示搜索结果。sidebar Logo 用 `<Link href="/">` 在 SPA 模式下当前已在 "/" 路径，点击无反应。
- **修复文件**: `src/app/page.tsx`, `src/components/website/sidebar.tsx`
- **改动**: `goHome`/`handleCollectionChange`/`handleFolderSelect` 均清空 `searchQuery`+`searchScope`；Logo 改为 `onClick={handleGoHome}`。

### Bug 2 - 色调模式在夸克/手机浏览器失效
- **根因**: `ThemeProvider` 中 `localStorage.getItem/setItem` 无 try-catch。夸克等 WebView 浏览器在隐私模式或存储受限时 localStorage 会抛异常，导致主题状态更新中断，toggleTheme 完全失效。
- **修复文件**: `src/components/providers/ThemeProvider.tsx`
- **改动**: 封装 `safeGetItem`/`safeSetItem` 加 try-catch；初始化时增加 `prefers-color-scheme` 媒体查询回退。

### Bug 3 - 新建/删除文件夹加载延迟
- **根因**:
  1. `POST /api/folders` 创建文件夹后未调用 `revalidateTag`，`unstable_cache` 30秒缓存未失效。
  2. `/api/collections/[id]/folders` 有 `unstable_cache` + 浏览器 `Cache-Control: max-age=15` 双重缓存，新建/删除后 fetch 返回旧数据。
  3. `admin/bookmarks/page.tsx` 所有 fetch 未禁用浏览器缓存。
- **修复文件**: `src/app/api/folders/route.ts`, `src/app/api/collections/[id]/folders/route.ts`, `src/app/admin/bookmarks/page.tsx`, `src/components/folder/CreateFolderDialog.tsx`
- **改动**:
  - POST 成功后 `revalidateTag('folders-${collectionId}')` + `revalidateTag('collections')`
  - 去掉 `unstable_cache`，响应头改为 `Cache-Control: no-store`
  - admin 页面所有 fetch 加 `{ cache: 'no-store' }`
